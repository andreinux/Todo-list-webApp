# TaskFlow

A simple and modular **To-Do List application** built with JavaScript as part of **The Odin Project**.

TaskFlow lets users organize their work into projects and manage tasks with descriptions, deadlines, and priority levels.

## Built With

* HTML
* CSS
* JavaScript
* Webpack
* LocalStorage

## Purpose

TaskFlow is not intended to compete with existing productivity applications. The purpose of building it is to gain practical experience developing a complete application from the ground up.

The project serves as practice for understanding how individual pieces of code communicate with each other to form a functioning system.
